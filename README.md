# 박윤권 · Frontend Developer

## 👋 About

커머스와 여행·숙박, 광고 서비스의 프론트엔드를 개발해 온 **박윤권**입니다.  
**React · TypeScript · Next.js**를 중심으로 화면을 만들고, 서비스의 제약에 맞춰 성능과 개발 환경을 점진적으로 개선합니다.

노스페이스 공식몰 기획전 페이지의 로딩 병목을 측정하고 개선해 **LCP를 5.6초에서 2.2초로, Lighthouse 성능 점수를 13점에서 77점으로** 개선했습니다. 레거시 PHP 서비스에 React를 점진적으로 도입하고, 두 환경이 함께 사용하는 채팅 SDK 래핑 패키지를 설계해 GitHub Packages로 배포했습니다.

팀이 반복해서 겪는 불편을 줄이는 일에도 관심이 있습니다. 번역 시트와 배포 파이프라인을 연결하고, 수동 배포를 GitHub Actions로 자동화했습니다. AI 코딩 도구가 프로젝트 규칙과 문서를 참고해 반복 작업을 수행하도록 구성하는 등, 코드와 협업 과정 모두를 개선하고 있습니다.
